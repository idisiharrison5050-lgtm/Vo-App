# Vo-App Roadmap

## Stage 0 — Foundation
- Laravel and Flutter repositories/modules
- Environment configuration
- Database and domain boundaries
- API conventions
- Design system
- CI and test foundation

## Stage 1 — Commercial MVP
- Authentication
- Wallet and ledger
- Countries/services
- Number inventory
- Temporary/monthly/annual products
- Orders and assignments
- SMS inbox
- Provider adapter
- Webhooks
- Realtime updates
- Notifications
- Premium mobile UX

## Stage 2 — Reliability
- Provider failover
- Reconciliation
- Queue monitoring
- Scheduler
- Expiry and renewal automation
- Advanced observability
- Abuse/risk controls
- Performance hardening

## Stage 3 — Growth
- Business accounts
- Teams
- Dedicated numbers
- Subscriptions/invoices
- Advanced analytics
- Multiple capabilities including calling
- Number portability
- Enterprise controls

## Definition of Done
A feature is not complete until its domain behavior, API contract, UI states, security controls, tests and documentation are complete. Critical money movement and number lifecycle paths require automated tests and idempotency.
